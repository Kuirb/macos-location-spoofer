# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| `main` | Yes |
| Most recently published GitHub release, including prereleases | Yes |

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Kuirb/macos-location-spoofer/security/advisories/new). Do not report security issues in public issues, discussions, commits, or pull requests.

Never publish secrets, CA material, private keys, personal coordinates, raw payloads, or unsanitized logs. Provide the smallest sanitized reproduction and expected impact instead.
